# Gothic Sheets

## About
This is my attempt to create datasheets for the tabletop game Battlefleet Gothic (BFG) (published 1999 by GamesWorkshop), as well as to provide a nice starting point for new players.

## Templates

This repository contains 2 SVG templates, created with [Inkscape](https://inkscape.org/):

* [Capital Ship](Templates/Capital_Ship_A6.svg) (148mm x 105mm, A6 format)
* [Escort Ship](Templates/Escort_Ship_80x120.svg) (120mm x 80mm, "Dixit" format)

Use Inkscape to create new datasheets from these templates. The fonts used in the templates can be found in the [Assets](Assets/Fonts/) folder.

Make sure to use the templates for creating new datasheets instead of modifying existing ones.
They may contain fixes and improvements that have not yet been applied to the existing datasheets.

## Rules

The latest official BFG rules, originally published by Games Workshop in various books and FAQs, have been compiled into two "remastered" rulebooks.
The PDFs can be downloaded for free at [horizon-bfg.infinityfree.me](https://horizon-bfg.infinityfree.me).
To play, you'll need both the "Remastered Official Rulebook" and the "Remastered Official Fleets Book".

There are online (HTML) versions of both books available at [https://battlefleet-game.org/](https://battlefleet-game.org/).

If you prefer a nicely printed version of the rulebook, check out [this video](https://www.youtube.com/watch?v=EYfSbst3iNg) by Simon Saier, the maintainer of the "Remastered Rulebook".
He also offers higher quality PDFs intended for printing [here](https://linktr.ee/bfg.remastered).

## Markers

BFG requires various markers for play, such as blast and ordnance markers. You can find lots of them in the [Markers](Assets/Markers) folder.

While even more markers can be found for free online, be sure to check their sizes before using them. Here’s a list of the sizes (width x height) for some of the most important BFG markers:

* Attack craft: 20mm x 20mm
* Torpedoes: 25mm x 20mm
* Blast marker: 30mm x 25mm
* Nova cannon template: 50mm

Many markers can be replaced with 3D printed tokens. Here are some examples:

* Attack craft: [Barracudas (Cults3D)](https://cults3d.com/en/3d-model/game/battlefleet-gothic-tau-ordinance)
* Torpedoes: [Cults3D](https://cults3d.com/en/3d-model/game/torpedo-tray-for-12mm-die)
* Blast markers: [Thingiverse](https://www.thingiverse.com/thing:3529981)
* Nova cannon template: [Cults3D](https://cults3d.com/en/3d-model/game/bfg-nova-cannon-template)
* Compass: [Cults3D](https://cults3d.com/de/modell-3d/spiel/battlefleet-gothic-3d-compass)
* Special orders (dice): [Cults3D](https://cults3d.com/en/3d-model/game/battlefleet-gothic-orders-dice-supported)
* Special orders (flat): [Thingiverse](https://www.thingiverse.com/thing:3543728)

## Miniatures

Official miniatures from GW are no longer in production, but there are many alternatives to explore.

If you have access to a 3D printer, be sure to check out the two "Starter Kits":

* [Battlefleet Gothic Starter Kit](https://drive.google.com/drive/folders/1Kpg6ZuDmFc5axXa6sUBiJrQiFuZIlbAu)
* [Battlefleet Gothic Starter Kit Advanced ](https://drive.google.com/drive/folders/1dxTeLC2bTnlUfzN_RJF788wHmYBhMa6C)

In addition to STL files for the ships, they also include rules and markers.

More STLs are available from various sources. Here are some of them:

* [Italianmoose](https://cults3d.com/en/users/Italianmoose/3d-models)
* [Tempest Shipyards](https://cults3d.com/en/users/Tempest_Shipyards/3d-models)
* [Fusion Shipyards](https://cults3d.com/en/users/Fusion_Shipyards/3d-models)
* [Arcane Shipyard](https://cults3d.com/en/users/ArcaneShipyard/3d-models)
* [Space Cowboys](https://cults3d.com/en/users/SpaceCowboys/3d-models)
* [ArcaneEternal](https://makerworld.com/de/collections/3306018-battlefleet-gothic)

If you prefer purchasing physical miniatures, there are various shops available, such as:

* [Battlefleet Galaxy](https://battlefleetgalaxy.com/) (UK)
* [Scourge Scenics](https://www.scourgescenics.co.uk/shop/product-category/space-combat) (UK)
* [TableTopStuff](https://tabletop-stuff.de/Battlefleet-Colossus/) (DE)

## Contributing
